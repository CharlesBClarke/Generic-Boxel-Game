# Friction log

What slowed the work down, one line each: date, slice, what, rough cost. Added at Close (see `CLAUDE.md`). When the same kind of friction shows up a third time, raise it and suggest a fix (a seam, a script, a recipe, a doc paragraph, a refactor). Delete entries once fixed.

- 2026-11-05, local server seam: every test crate (sim tests, client, server) defines its own `base_sim()` that loads the base mod natively; client tests needed a lint exception to do it. A shared test helper (say a `testing` crate) would remove the copies.
- 2026-11-05, sound: `kira` 0.12 couldn't be built beside Bevy 0.18: both pull `alsa-sys` through different `cpal` versions, and Cargo refuses two crates linking the same native library even when one is behind a switched-off feature. Cost a few rounds of checking versions; settled on `kira` 0.10.8.
- 2026-11-05, sound: the full workspace test run took up to ten minutes after dependency changes (cold builds of `kira`, Bevy's feature list), pushing runs into the background. Running the touched crate's tests first and the workspace once at the end kept it moving.
- 2026-11-05, sound: iterating on sound by ear needed tooling built mid-verify (an audition script, F5 reload, pick lists that save). It's here now; other feel toys may want the same pick-from-a-library pattern for looks or models.
- 2026-11-05, cow tweaks: `base/src/cow.rs` is about 1500 lines (brain plus its tests), past the reader's page size, so it reads in pieces. Splitting the tests into their own file would help.
- 2026-11-05, cow tweaks: herd-wide brain rules break unrelated world tests in `sim/tests/combat.rs` (4 here), since every test runs the real herd; each needed working out whether it was a real problem (two were) or a test that should turn the new rule off. A small set of named test herds (timid, quiet, no grudges) would make that quicker.
- 2026-11-05, generated terrain: the cow tests in `sim/tests/combat.rs` count and herd every target, so adding herds elsewhere in the base world broke 5 of them; `Simulation::keep_targets` fixed it. Second time world-wide changes broke these tests (first: cow tweaks); the named test herds proposed there would cover both.
- 2026-11-05, shading: every AO slider step remeshed the whole terrain, which froze the game at 512³ and up; fixed with an Apply button. Live sliders that remesh need a guard once the world is big.
- 2026-11-05, shading: no way to see the game's window from a session (`import` can't capture under Wayland), so shader output was only checked for compile errors, never looked at. A dev screenshot key writing to the data folder would let the agent see a frame.
- 2026-11-06, cow pathfinding: making angry cows able to leave the pasture broke a world test whose premise was the opposite (a cow can't get out). Tests that pin a limitation rather than a behavior are worth naming as such, so it's clear they're meant to change.
- 2026-11-06, WebAssembly behavior seam: adding one mod (`BaseCowMod`) meant editing the mod list in 13 places across `sim`, `server`, `client` and `game` tests. Second time for the copied `base_sim()` helpers (first: local server seam); a shared test helper would make it one edit.
- 2026-11-06, WebAssembly behavior seam: wit-bindgen's export macro takes only a plain type name (no generics), WIT reserves `from`, and only one file in a package may have comments before `package`. Three build rounds to learn; worth a line in the notes for the next `.wit`.
- 2026-11-06, functional crafting: rules grew by fixing annoyances one at a time (the hinge's axis and direction tiebreaks and slide; placement before it), and the user found the result arbitrary. A checklist for rules, checked before building, is proposed in `docs/notes/material-behavior.md`.
- 2026-11-06, functional crafting: the toy grew mid-verify (layout fixes, a grid per view, loading, a frame bug, then a redesign of what materials do) until the context got heavy, and was split at close. Splitting as soon as a redesign shows up would keep toys short.
- 2026-11-06, functional crafting: `sim/tests/doors.rs` copied `base_sim()` again (third time, after the local server and WebAssembly behavior seams). A shared test helper crate would end the copies.
- 2026-11-06, material behavior: three rounds to understand the user's short answers ("grab all the boxels around it", "I ment texles"). Restating each reading with a concrete example (what happens to a door frame) got there; leading with the example would save a round.
- 2026-11-06, material behavior: the plan didn't check the four-occupant limit against what the toy builds, though cutting a piece adds an occupant; the user hit it in play. Checking engine limits against the toy's own test pieces at planning would catch this.
- 2026-11-07, saving: `sim/tests/saving.rs` and the server tests needed `base_sim()` again (fourth and fifth copies, after the local server, WebAssembly behavior and functional crafting). Past the third time: a shared test-helper crate (base sim, small terrain, stand/aim helpers) is worth a fix branch.
- 2026-11-07, saving: a test teleported the player 300 boxels up to land on the terrain; the fall killed them and the knock-out silently sent them to spawn, so the test dug in the wrong chunk until an extra assertion caught it. Test helpers that move the player should check where they ended up.
- 2026-11-07, blueprint library: `sim/tests/blueprints.rs` copied `base_sim()` a sixth time. Raised again: a shared test-helper crate is overdue.
- 2026-11-07, blueprint library: a session's notes recorded "inside and out" as the user's words; they never said it, and it took a round to find out it meant a shift. Notes should quote the user or mark a paraphrase as one.
- 2026-11-07, blueprint library: the menu grew by adding a column and rows of buttons, and the user found it too heavy only once built. Sketching a menu's layout (ASCII in the plan) before building would surface that at planning.
- 2026-11-07, blueprint library: pictures could only be judged by the user in play until a throwaway test rendered egui output to images; that caught and confirmed the spin streaks. A kept helper (render a UI closure to a PNG) would let the agent look at menus and icons.
